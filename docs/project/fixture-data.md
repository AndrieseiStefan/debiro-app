Seed dates, browser-memory mutation timestamps, date-range filters and deterministic captures use this reference. It is explicitly demo-only: no global/production clock is replaced. UTC calendar-day differences are independent of locale, time-of-day and DST. Pure expiry calculation takes an explicit clock and preserves the requirement's snapshotted warning period, with the existing 30-day default.

Notifications expiry rows derive from accepted current documents; missing rows derive from actual requirements lacking a current file, including optional missing requirements as in Details. No requirement deadline exists in this model, so the deadline cell is `—`. Recent activity also projects successful local audit actions without creating delivered/unread notifications. Audit, activity and bell date labels derive from timestamps/reference time, not independent rendered offsets. Dashboard's existing vendor metrics, expiry/missing table and supported recent-event kinds project the same sources; no new Dashboard status or interaction is introduced. The existing monthly comparison baselines remain historical sample values.
