# Feature Documentation

Do not pre-create feature specifications. A feature document is created by the task that defines or implements that feature, and it documents actual current requirements and behavior.

Implemented screen records: [landing page](landing-page.md) and [onboarding](onboarding.md).

For example, the Supplier Upload Portal task will implement its behavior and create `docs/features/supplier-upload-portal.md` in the same task. Until then, the roadmap may name the direction, but no detailed feature contract should exist.
