# Onboarding Screen

E1-002 implements the first-step screen in [canonical mockup 02](../design/mockups/02-onboarding.png) at `/onboarding` and `/en/onboarding`. The Romanian mockup copy is preserved with placeholder branding replaced by `DEBIRO`; English is translated for review. The page reuses PublicHeader, Button, Field, Surface, and Divider. A deterministic typed fixture supplies visible sample values; editing, password visibility, native required-field/password-rule validation, and terms selection are local to the browser.

The screenshot depicts step 1 of 3. Later steps, submission, persistence, authentication, legal destinations, and help destination are not implemented. The Continue button does not advance or send data. The industry, company-size, and country selectors reproduce the visible choices only, without inventing unapproved option sets. The shared top header omits the former secondary brand tagline and contains only `DEBIRO`, help, and RO/EN; help moves to a centered second row when those elements no longer fit. Help and legal text have no destinations yet.

The desktop mountain landscape is a generated decorative approximation; the right quote illustration is built in CSS. Neither the mockup nor a captured screenshot is rendered as the interface. Responsive reflow follows the [UI foundation](../design/ui-foundation.md#responsive-contract). Generated visual captures remain unapproved and ignored.
