# Design Principles

debiro should be:

- Modern
- Clean
- Polished
- Premium but approachable
- Low in visual noise
- Strong in hierarchy
- Generous with whitespace
- Purposeful with status colors
- Obvious about primary actions
- Operationally clear
- Responsive
- Accessible
- Ready for Romanian and English

> Complexity behind the scenes. Clarity in front.

Avoid generic admin-dashboard aesthetics, dense ERP interfaces, government-style interfaces, unnecessary configuration, arbitrary redesign, and excessive visible complexity. Supplier-facing surfaces should be even simpler than authenticated customer surfaces.

Where an approved mockup exists, it overrides generic design interpretation.
